# Roadmap

## Completed engineering work on D1

1. CT volume inspection and oriented central slices.
2. Verified NRRD-to-NIfTI conversion, pretrained aorta inference and technical mask checks.
3. Reference segmentation metadata, voxel and geometry inspection.
4. Descriptive mask-region counts and comparison overlays with a selected-image user review.

These are single-case preliminary experiments, not clinical validation or model training. Actual observations and commands are recorded in each experiment README. Data and outputs remain local.

## Future work (not performed)

- Obtain the reference annotation protocol and independently match anatomical scope with the model class.
- Arrange expert review and, if needed, independent CT-based aorta/branch reference labels.
- Only then design reference-based metrics and a multi-case evaluation protocol.
- Explore paired-image geometry or a trainable baseline as separate experiments with documented public datasets and subject-level splits.

No future item is presented as an observed result.
